# uno-server
A UNO Game server written in Go

这是 Linserin 练习 Go 的项目，目前正在完善...

路由：
- `/`: 前端开发控制台（静态资源通过 `go:embed` 打包）
- `/ping`: 测试服务器
- `/newRoom`: 创建新房间并发牌（每个玩家发牌 7 张）
- `/fetchPlayerCards`: 获取指定玩家的牌，使用查询方法
